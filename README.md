# AURA AI — نسخه آغازین

پروژه‌ی فارسی و واکنش‌گرا با حالت آنلاین، چت آفلاین مبتنی بر WebLLM و قابلیت نصب به‌شکل PWA.

## نکته‌های مهم پیش از انتشار
- «بدون باگ» را نمی‌توان تضمین کرد؛ این نسخه‌ی اولیه است و باید روی دستگاه‌ها و مرورگرهای هدف آزمایش شود.
- چت آفلاین از WebLLM و WebGPU استفاده می‌کند. پشتیبانی WebGPU در همه‌ی گوشی‌ها/مرورگرها یکسان نیست. در دستگاه ناسازگار، حالت آفلاین اجرا نمی‌شود.
- مدل در اولین راه‌اندازی آفلاین دانلود می‌شود و ممکن است چندصد مگابایت یا بیشتر فضا و اینترنت بخواهد. پس از آماده‌شدن، کتابخانه مدل را در حافظه‌ی مرورگر نگه می‌دارد.
- تولید تصویر و سایر ابزارهای آنلاین هنوز در این نسخه پیاده‌سازی نشده‌اند؛ فعلاً هسته‌ی چت آماده شده است.
- برای PWA و Service Worker باید پروژه از HTTPS یا localhost اجرا شود؛ بازکردن مستقیم فایل `index.html` کافی نیست.

## اجرای رابط کاربری محلی
در ریشه پروژه:
```bash
python -m http.server 8080
```
سپس `http://localhost:8080` را باز کن.

## تنظیم سرور آنلاین
1. وارد پوشه `backend` شو.
2. محیط مجازی بساز و وابستگی‌ها را نصب کن:
```bash
python -m venv .venv
# ویندوز:
.venv\\Scripts\\activate
# مک/لینوکس:
source .venv/bin/activate
pip install -r requirements.txt
```
3. متغیرهای محیطی را روی سرور تنظیم کن؛ کلید API را هرگز داخل فایل‌های فرانت‌اند یا GitHub قرار نده:
```bash
AI_API_KEY=کلید_خصوصی
AI_API_URL=https://api.openai.com/v1/chat/completions
AI_MODEL=gpt-4o-mini
ALLOWED_ORIGINS=https://YOUR-GITHUB-PAGES-DOMAIN
```
4. اجرا:
```bash
uvicorn server:app --host 0.0.0.0 --port 8000
```
5. فایل `config.example.js` را به `config.js` تغییر نام بده و مقدار `API_BASE` را آدرس HTTPS سرور قرار بده.
6. `config.js` را به `.gitignore` اضافه کن تا تنظیمات خصوصی اشتباهی منتشر نشود.

## انتشار روی GitHub Pages
- کل پوشه‌ی فرانت‌اند را در یک مخزن GitHub قرار بده.
- در Settings → Pages، انتشار از شاخه‌ی اصلی و پوشه‌ی ریشه را فعال کن.
- بک‌اند Python باید جداگانه روی یک میزبان پشتیبان Python منتشر شود؛ GitHub Pages فقط فایل‌های ایستا را میزبانی می‌کند.
- پس از انتشار، آدرس نهایی سایت را به `ALLOWED_ORIGINS` در سرور اضافه کن.

## فایل‌های اصلی
- `index.html`, `style.css`, `app.js`: رابط و منطق چت
- `manifest.json`, `service-worker.js`: قابلیت نصب و کش پوسته
- `backend/`: واسط امن API
- `config.example.js`: نمونه تنظیمات فرانت‌اند

## وضعیت قابلیت‌ها در این نسخه
- رابط فارسی راست‌چین و واکنش‌گرا: پیاده‌سازی شده
- تاریخچه چت محلی: پیاده‌سازی شده
- پوسته روشن/تاریک: پیاده‌سازی شده
- نصب PWA و کش پوسته: پیاده‌سازی شده
- اتصال آنلاین از طریق بک‌اند: آماده‌ی تنظیم
- چت آفلاین با مدل محلی: پیاده‌سازی آزمایشی، نیازمند WebGPU و دانلود اولیه مدل
- تولید تصویر/ترجمه تخصصی/ابزارهای دیگر: مرحله بعد

## حریم خصوصی
گفت‌وگوها در این نسخه در `localStorage` مرورگر ذخیره می‌شوند. از واردکردن اطلاعات حساس خودداری کن. برای استفاده عمومی، سیاست حریم خصوصی، محدودیت نرخ درخواست، احراز هویت و مدیریت داده‌ها اضافه شود.
